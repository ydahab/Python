في آخر الدرس هتقدروا تختاروا اللون بالاسم، أو بالـ hex، أو بدالة آر جي بي، أو بدالة إتش إس إل. وتنسّقوا النص بـ font-family وfont-size وline-height وtext-align. وتخزّنوا القيم اللي بتتكرر في متغيّرات. والمصطلحات: الـ Hex code لون مكتوب بعلامة الشباك وست خانات: أحمر وأخضر وأزرق بالنظام السداسي عشر. والوحدة، Unit، بتقول الرقم بيقيس إيه: بكسل، أو rem، أو نسبة مئوية. والـ Typeface عيلة الخط زي Arial، وفي سي إس إس بنكتبها font-family. ومتغيّر سي إس إس اسم بنعرّفه بشرطتين، وبنستخدمه بدالة var.
