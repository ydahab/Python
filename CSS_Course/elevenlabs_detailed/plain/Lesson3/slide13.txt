… … … تلات أسئلة. «سمِّ طبقات نموذج الصندوق من الداخل إلى الخارج». … … … المحتوى، الحشو، الإطار، الهامش. «صندوق: width ميتين، padding عشرة، border خمسة solid. ما عرضه الكلي مع box-sizing الافتراضي؟». … … … الإجابة: مئتين وتلاتين. ميتين، زائد اتنين ضرب عشرة، زائد اتنين ضرب خمسة. ومع border-box يبقى ميتين. «لماذا لا يوسّط span، margin صفر auto، النص؟». … … … الإجابة: لأن span عنصر سطري، فيتجاهل الهوامش التلقائية. اجعله display، block، وأعطه عرضًا.
