للي خلّص النشاط بسرعة، جاهز لتحدّي أصعب شوية. الشريحة هنا بخلفية غامقة، وعلامة وردية مكتوب عليها «تحدٍّ». والوقت المتوقّع خمسة وعشرين دقيقة. الفكرة: «نسّق القائمة بالمحدِّدات التي تعرفها فقط، دون تعديل إتش تي إم إل». يعني ممنوع نفتح ملف الـ إتش تي إم إل. وعندنا عنوان «School Clubs»، وتحته قايمة من أربع نوادي: Robotics، وCoding، وChess، وPhotography. وبعض النوادي لها class اسمه open، ونادي واحد class اسمه full، ونادي Coding له كمان id اسمه featured. المطلوب، خطوة خطوة: الأولى: كل عنصر قايمة li ياخد حشو وأركان مدوّرة، وبلا نقاط، بخاصية list-style بقيمة none. التانية: النوادي المفتوحة، class اسمه open، خلفيتها خضرا فاتحة ونصها أخضر داكن. التالتة: النوادي الممتلئة، class اسمه full، رمادية، ومشطوب عليها بـ text-decoration بقيمة line-through. الرابعة: نادي Coding المميّز بالـ id، خلفيته ذهبية. وفي الآخر سؤال: «هل يتغلب على open؟ ولماذا؟». فكّروا قبل ما تجرّبوا. … … … النادي ده ليه class اسمه open، وكمان id اسمه featured. والقاعدتين بتديه لونين مختلفين. مين هيكسب؟ الإجابة: الـ id. لأن المعرِّف أكتر تحديدًا من الفئة، زي ما اتعلّمنا في الشريحة التالتة. فهيبقى ذهبي. وللأذكياء: «أضف li hover ليحصل النادي الذي يمرّ عليه المؤشر على إطار أزرق». وده بيجمع الـ pseudo-class مع الأولوية. والصورة اللي على الشمال هي الهدف، مع الحل في مجلد challenge، ثم solution.
